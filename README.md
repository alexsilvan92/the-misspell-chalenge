# 🧩 The Misspell Challenge
<!-- endhide -->

Learning in public means **collaboration**, and you don't have to be an expert to contribute.  
Misspellings come to the rescue! 🪄  
The perfect **ice-breaker** for open-source contributions: fixing a misspell is easy and requires almost no experience with **GitHub** or **Git**.

## 🔷 How to fix a misspell in a 4Geeks lesson:

![edit on Github](https://github.com/breatheco-de/the-misspell-chalenge/blob/master/assets/github-logo2.png?raw=true)

1. Click the pencil icon labeled **"Edit on GitHub"** at the top right of the lesson. The lesson source file will open for editing.  

2. Correct the misspelling you found in the lesson.  

3. Finally, click **"Pull Request"** to propose the change.  

## 📝 Instructions:

1. Find a **misspelling** in any 4Geeks lesson, project, or exercise and create a **pull request** with your fix.  

> 👉 **IMPORTANT:** Look for another project to fix, this one has already been corrected enough 😂
